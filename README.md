# 🎡 Spin — колесо вибору фільмів

Завантажуй фільми, задавай кожному «значення» (вагу), крути колесо — воно
обирає фільм із шансом, пропорційним вазі. **Переможець рахується на бекенді**
(його не можна підмінити в браузері), а колесо лише докручується до нього.

## Стек

| Шар | Технології |
|---|---|
| Фронтенд | Vue 3 + TypeScript + Vite + Pinia + Vue Router |
| Бекенд | NestJS + TypeScript + Prisma |
| БД | PostgreSQL (у Docker) |
| Авторизація | JWT (email + пароль) |

## Структура

```
Spin/
├── docker-compose.yml     # Postgres для локальної розробки
├── backend/               # NestJS API
│   ├── prisma/schema.prisma
│   ├── uploads/           # завантажені постери (роздаються на /uploads)
│   └── src/
│       ├── auth/          # реєстрація / вхід (JWT)
│       ├── wheels/        # колеса, позиції (WheelItem), СПІН (вибір на бекенді)
│       ├── movies/        # бібліотека фільмів + завантаження постера
│       └── genres/        # каталог жанрів (вибір чипсами)
└── frontend/              # Vue 3 SPA
    └── src/
        ├── views/         # Auth, Wheels (список), Movies (бібліотека), Wheel
        ├── components/    # SpinWheel.vue — колесо + анімація + конфеті
        └── stores/        # Pinia (auth)
```

## Модель

- **Бібліотека** (`Movie`) — фільми користувача: назва, опис, бали IMDb, постер
  (URL або завантажений файл), рік, жанри. Сторінка **«Мої фільми»**.
- **Колесо** містить **позиції** (`WheelItem`) — фільм із бібліотеки + його **вага**.
  Один фільм можна класти в багато коліс. Бали IMDb — окремо від ваги; на сторінці
  колеса є кнопка **«Заповнити ваги балами IMDb»**.

## Запуск (локально)

Потрібні: Node 20+, Docker.

### 1. База даних

```bash
docker compose up -d          # піднімає Postgres на localhost:5432
```

### 2. Бекенд

```bash
cd backend
npm install
npx prisma migrate dev        # застосує міграції (перший раз створить схему)
npm run start:dev             # http://localhost:3000/api
```

### 3. Фронтенд

```bash
cd frontend
npm install
npm run dev                   # http://localhost:5173
```

Відкрий **http://localhost:5173**, зареєструйся — і можна створювати колеса.

## Фільми

Фільми додаються вручну на сторінці «Мої фільми»: назва, постер (URL або
завантаження файлу), рік, жанри (вибір чипсами з каталогу), рейтинг. Є масовий
**імпорт/експорт JSON** (кнопки на сторінці; приклад формату —
`frontend/public/movies.example.json`).

## Як працює спін

1. Фронт викликає `POST /api/wheels/:id/spin`.
2. Бекенд бере фільми колеса, робить **зважений випадковий вибір**
   (шанс = вага / сума ваг), записує подію в історію й повертає
   `{ index, winner }`.
3. Фронт анімує колесо так, щоб сектор `index` зупинився під стрілкою,
   і показує переможця + конфеті.

## Змінні оточення (`backend/.env`)

| Змінна | Опис |
|---|---|
| `DATABASE_URL` | рядок підключення до Postgres |
| `JWT_SECRET` | секрет для підпису токенів (зміни у проді) |
| `JWT_EXPIRES_IN` | час життя токена (напр. `7d`) |
| `PORT` | порт бекенду (3000) |
| `CORS_ORIGIN` | дозволений origin фронту (`http://localhost:5173`) |
