# Колесо вибору фільмів — опис функціоналу

Веб-застосунок для **зваженого випадкового вибору фільму** з власної бібліотеки.
Ти збираєш бібліотеку фільмів, складаєш із них колеса, задаєш вагу (шанс) кожному
й крутиш — колесо обирає переможця з урахуванням ваг. Переможець рахується на
**бекенді**, фронт лише анімує зупинку на ньому.

**Стек:** Vue 3 + TypeScript + Vite + Pinia (фронт) · NestJS + Prisma (бек) ·
PostgreSQL у Docker · автентифікація JWT. Усі дані (фільми, жанри, колеса,
історія) зберігаються в БД і переживають перезавантаження.

---

## Автентифікація

- Реєстрація та вхід за **email + пароль**; сесія тримається на JWT-токені
  (у `localStorage`). Кожен користувач бачить лише свої фільми, жанри й колеса.

---

## Сторінка «Мої фільми» (бібліотека)

Особиста бібліотека фільмів, незалежна від коліс — один фільм можна класти в
будь-яке колесо.

### Картка фільму
- Постер, бейдж рейтингу **IMDb** (★, 0–10), назва + рік, короткий опис.
- **Жанри — чипсами** (не через кому).
- Статус перегляду: «Переглянуто · дата» або «Не переглянуто».
- Дії: **редагувати**, **додати в колесо** (⊕), **позначити переглянутим** (око),
  **видалити**.

### Додавання / редагування
Форма з полями: назва, опис, бали IMDb, рік, постер, жанри, перегляд.

- **Постер** — вставити URL картинки **або завантажити файл** (зберігається на
  сервері й роздається за `/uploads/...`).
- **Жанри** — вибір **чипсами** з каталогу: клік додає/знімає жанр. Поле
  «Новий жанр + Enter» створює жанр у каталозі й одразу обирає його.

### Каталог жанрів (керований)
Єдиний перелік жанрів користувача — щоб не вписувати їх щоразу вручну.

- Панель **«Керувати каталогом»**: додати, **перейменувати**, **видалити** жанр.
- Перейменування/видалення **каскадно** оновлює жанри в усіх фільмах (перейменування
  зливається з наявним жанром без дублів; видалення прибирає жанр із фільмів).
- Кольорові смужки/свотчі жанрів синхронізовані з кольорами секторів колеса.

### Позначка перегляду (модалка з датою)
- Клік по **оку** відкриває вікно з вибором **дати перегляду** (за замовчуванням —
  сьогодні або наявна дата).
- Кнопки: **позначити переглянутим / зберегти дату**, а для вже переглянутого —
  **прибрати позначку**, і **скасувати**. Enter зберігає, Esc/клік повз — закриває.

### Пошук і фільтри
Над бібліотекою:
- **Пошук за назвою** (підрядок, без урахування регістру);
- **фільтр по жанрах** — чипси (показуються фільми, що містять **усі** обрані жанри);
- **статус перегляду** — перемикач **Всі / Переглянуто / Не переглянуто**;
- кнопка **«Скинути»**; лічильник показує `знайдено / усього`, коли фільтр активний.

### Додати фільм у колесо
- Кнопка **⊕** на картці відкриває модалку зі **списком усіх твоїх коліс** (з
  кількістю фільмів у кожному).
- Клік по колесу додає фільм туди (позиція з вагою 1). Повторне додавання
  безпечне — дубля не буде. Можна додати в кілька коліс поспіль.

### Імпорт / експорт JSON
- **Імпорт з JSON** — масове додавання фільмів із файлу. Приймається масив
  `[ … ]` або обʼєкт `{ "movies": [ … ] }`. Обовʼязкове лише `title`; числа й
  жанри коерсяться мʼяко (жанри — масивом або рядком через кому). Нові жанри
  автоматично додаються в каталог. Записи без назви пропускаються.
- **Приклад формату** — `frontend/public/movies.example.json` (кнопка «Приклад JSON»).
- **Експорт** — вивантажує **всі** фільми у той самий формат (round-trip:
  експортований файл можна одразу залити назад).

Допустимі поля запису: `title` (обовʼязкове), `description`, `imdbRating` (0–10),
`posterUrl`, `year`, `genres`, `watched`, `watchedAt` (ISO-дата).

## Сторінка «Колеса» (список)

- Перелік усіх коліс користувача з кількістю фільмів у кожному.
- Створення нового колеса та видалення наявного.

---

## Сторінка «Колесо»

### Ліва панель
- **01 — Фільми в колесі**: пікер бібліотеки (пошук + додавання фільмів, яких ще
  немає в колесі), список позицій із **вагою** кожної (поле, крок 0.5), кнопка
  прибрати з колеса. Кнопка **«★ Заповнити ваги балами IMDb»** проставляє ваги за
  рейтингами.
- **02 — Шанси**: для кожної активної позиції — колірний маркер, назва, множник
  ваги (`×N`) і **обчислений відсоток** шансу.
- **Налаштування** (див. нижче).

### Налаштування (зберігаються локально)
- **Час прокручування** — повзунок **2–60 с**; колесо помітно крутиться усю задану
  тривалість і зупиняється саме тоді.
- **Режим**: **Переможець** або **На вибування** (див. нижче).

### Колесо й спін
- Кожен фільм — **сектор**, кут пропорційний вазі; у секторі показується **постер**
  фільму (SVG-клин, коректно для будь-якого кута). 8 виразно різних кольорів
  секторів, легенда в панелі збігається за кольором.
- Запуск — центральна кнопка **Start / Roll** (недоступна, поки активних фільмів < 2).
- Механіка: спершу **зважений випадковий вибір переможця на бекенді**, далі колесо
  докручується до нього. Гальмування рівномірне (`easeOutQuad`), кількість обертів
  пропорційна часу. Вказівник «клацає» на межах секторів; після зупинки — **конфеті**.
- Блок **«Випало»** показує переможця останнього спіна.

### Режим «на вибування»
- Кожен прокрут **прибирає з колеса** того, хто випав; сектор зникає, шанси
  перераховуються. У списку «01» вибулі позначаються сірим/закресленими.
- Рядок **«Залишилось: N з M»** і кнопка **«↺ Відновити список»** (повертає всіх).
- Коли лишається **один** фільм — він фінальний переможець: показується **модалка
  переможця** (🏆 постер + назва) з кнопками «Відновити список» і «Закрити».

### Історія
- Останні спіни показані чипами внизу; кнопка **«Очистити»** видаляє історію цього
  колеса. Історія зберігається в БД (один запис на кожен спін).

## Спільне посилання та пропонування фільмів

### Публічне посилання на бібліотеку
- Кнопка **«↗ Поділитися»** в шапці бібліотеки видає посилання виду
  `/shared/<токен>`. Будь-хто з ним бачить список фільмів і фільтри — **лише
  перегляд**, без логіну.
- Токен один на акаунт: **«Створити нове»** перевипускає його (старе посилання
  одразу вмирає), **«Відкликати»** — вимикає доступ.

### Сесія пропонування
- У тій самій модалці можна **запустити пропонування**: обираєш колесо (наявне
  або нове за назвою) — і гості за посиланням отримують на кожній картці кнопку
  **«+ Запропонувати»**. Натиснув — фільм одразу стає позицією цього колеса.
- Запропоновані фільми помічені бейджем **«Запропоновано»** (з іменем, якщо його
  питали), плюс з'являється фільтр **Пропозиції: Усі / Запропоновані / Ще ні**.
  Сторінка гостя тихо оновлюється раз на 15 с, щоб було видно чужі пропозиції.
- Пропонувати можна **лише фільми зі списку власника**; скасувати свою пропозицію
  гість не може — прибрати фільм з колеса вміє тільки власник.
- **Опції сесії** (задаються при запуску): чи *питати ім'я гостя* і чи воно
  *обов'язкове*. Ім'я гість вводить один раз, далі воно живе в його `localStorage`.
  Опції зберігаються Json-полем `SuggestionSession.options`, тож нова опція не
  потребує міграції — див. `backend/src/suggestions/session-options.ts`.
- **«Закрити пропонування»** прибирає кнопки в гостей (сторінка знову лише для
  перегляду), а колесо з набраними фільмами лишається звичайним колесом.
  Активна сесія завжди одна: запуск нової закриває попередню.

## Дані та зберігання

Моделі Prisma (PostgreSQL, том Docker):

| Модель | Призначення |
|---|---|
| `User` | акаунт (email, хеш пароля, `shareToken` публічного посилання) |
| `Movie` | фільм бібліотеки (назва, опис, `imdbRating`, `posterUrl`, `year`, `genres[]`, `watched`, `watchedAt`) |
| `Genre` | каталог жанрів користувача (унікальна пара користувач+назва) |
| `Wheel` | колесо (назва) |
| `WheelItem` | позиція фільму в колесі + вага |
| `SpinHistory` | запис одного спіна (колесо, фільм, час) |
| `SuggestionSession` | сесія пропонування: колесо, опції (Json), `closedAt` |
| `Suggestion` | запропонований гостем фільм у межах сесії (+ ім'я гостя) |

## API (стисло)

Усі маршрути під `/api`, захищені JWT (крім реєстрації/входу).

| Метод + шлях | Що робить |
|---|---|
| `POST /auth/register`, `POST /auth/login` | реєстрація / вхід |
| `GET/POST /movies`, `PATCH/DELETE /movies/:id` | бібліотека фільмів |
| `POST /movies/upload` | завантаження постера-файлу |
| `POST /movies/import` | масовий імпорт із JSON |
| `GET/POST /genres`, `PATCH/DELETE /genres/:id` | каталог жанрів (rename/delete каскадять у фільми) |
| `GET/POST /wheels`, `GET/PATCH/DELETE /wheels/:id` | колеса |
| `POST /wheels/:id/items`, `PATCH/DELETE /wheels/:id/items/:itemId` | позиції колеса та їхні ваги |
| `POST /wheels/:id/items/weights-from-imdb` | заповнити ваги балами IMDb |
| `POST /wheels/:id/spin` | спін (опційно `{ itemIds }` — обмежити вибір активними позиціями) |
| `GET/DELETE /wheels/:id/history` | історія спінів колеса / очистити |
| `GET/POST/DELETE /movies/share` | публічне посилання: стан / створити (перевипустити) / відкликати |
| `GET /public/movies/:token` | **без JWT**: чужа бібліотека по токену + стан пропонування |
| `GET /suggestions/active`, `POST /suggestions`, `DELETE /suggestions/active` | сесія пропонування: стан / запустити / закрити |
| `POST /public/suggestions/:token` | **без JWT**: пропозиція гостя (`{ movieId, guestName? }`) |
